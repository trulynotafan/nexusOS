# NexusOS

A web-based operating system interface built with SvelteKit and TypeScript.

## What is it?

NexusOS provides a desktop-like experience in your browser with window management, a customizable dock, and a modern interface. It's responsive and works on both desktop and mobile devices.

## Tech Stack

- SvelteKit
- TypeScript 
- TailwindCSS
- Lucide Icons

## Getting Started

Clone the repository:
```bash
git clone https://github.com/trulynotafan/nexusOS.git
cd nexusOS
```

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

## Building

```bash
npm run build
npm run preview
```
